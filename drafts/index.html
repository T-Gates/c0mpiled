Human Check 통화 — 시안

각 시안 상단 노란 바에서 1~6 화면을 넘겨 보세요. 참여자 화면 클릭 → 판정 버튼으로 흐름도 눌러볼 수 있습니다. 영상·수치는 가짜입니다.

A · 다크 갤러리 (Zoom형)

3명 같은 크기 타일. 참여자 화면을 클릭해 선택하고, 아래 바의 "딥페이크 판정"을 누른다. 결과는 타일 위 배지로 표시.

B · 무대 + 판정 패널 (Human Check 톤)

선택한 사람을 크게 보고, 오른쪽 패널에서 대상 선택 → 판정. 색 단계 진행과 색별 반사 막대, 판정 기록이 패널에 쌓임. 지금 Human Check 화면과 같은 밝은 톤.

C · 검사 모드 확대

평소엔 갤러리. 아래 "대상" 드롭다운으로 고르고 판정하면 대상 화면이 크게 확대되고 얼굴 측정 위치가 표시됨. 끝나면 결과 서랍이 올라옴.
